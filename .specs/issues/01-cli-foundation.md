# 01: Create the Go CLI foundation

**What to build:** A runnable QBS command-line binary with command dispatch, version output, Git repository detection, and embedded template support.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] A Go module and executable entry point exist.
- [ ] The binary provides basic help and version output.
- [ ] Commands can detect the current Git repository and report clear errors outside a repository.
- [ ] Canonical AI templates can be embedded into the binary and read at runtime.
- [ ] Foundation behavior is covered by automated tests.
